# Initial Scope Baseline

## Authorized foundation work

- Git repository and frontend/backend project structure
- React, TypeScript, Django REST Framework, and PostgreSQL foundations
- Docker Compose, environment templates, continuous integration, tests, and API documentation
- Custom user model with coarse roles and fine-grained Django permissions
- Append-oriented application audit-log infrastructure
- Private file-storage abstraction
- Hardhat local blockchain development environment
- Draft, reversible database migrations
- Shared responsive frontend shell

## Explicitly deferred

- Final admission, eligibility, decision, and registration workflows
- Configured document requirements and grade/program rules
- Student-number generation
- Public credential and QR behavior
- Production blockchain network, wallet, and recovery configuration
- Official reports and notification delivery
- Production hosting and real student data
- Grade management, payments, schedules, and other student-information-system features

Changes to the deferred list require a recorded client decision and an updated acceptance baseline.
